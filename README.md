# Full Stacks Life

One desk. Nine jobs. The open-source projects stay upstream.

This is a homogeneous ledger for work that usually arrives as nine separate subscriptions: scheduling, support, projects, knowledge, dictation, voice, on-page search, capture, and motion. A bonus lab maps a paid product onto the station that already does the job.

The desk does not vendor those codebases. Each station does the job here, then links the real repository when you want the full self-hosted project.

| Station | Stands in for | Upstream |
| --- | --- | --- |
| Book | Calendly | [cal.com](https://github.com/calcom/cal.com) |
| Inbox | Intercom | [chatwoot](https://github.com/chatwoot/chatwoot) |
| Board | Asana | [openproject](https://github.com/opf/openproject) |
| Library | Notion AI | [WeKnora](https://github.com/Tencent/WeKnora) |
| Dictate | Wispr Flow | [openwhispr](https://github.com/OpenWhispr/openwhispr) |
| Studio | ElevenLabs | [VoiceStudio](https://github.com/debpalash/VoiceStudio) |
| Lens | Semrush | [open-seo](https://github.com/every-app/open-seo) |
| Stage | Loom | [Cap](https://github.com/CapSoftware/Cap) |
| Reel | Higgsfield | [open-higgsfield](https://github.com/wide-trace/open-higgsfield) |
| Lab (bonus) | a closed product | [REA](https://github.com/morluto/rea) |

Prices on the floor are illustrative published entry seats, not quotes. Star counts move. Lens scores paste, it does not crawl. Studio speaks with a voice already on the device. Reel copies a shot list, it does not spend a generation key. OpenSEO, if you self-host it, still calls a data API.

Same objects cross the stations: a dictation can become a note or a task, a script can become a take, a page score can become a note, a reel can open as a take.

## Deploy

The desk builds for Vercel (Nitro preset `vercel`), on the Fullstacks team. Railway stays for a long-running station — a database, or one of the upstream projects — not a second copy of this UI.
